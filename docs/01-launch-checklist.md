## B. 백엔드 / API / 결제

### B-1. 사용자 관리
- [ ] 회원가입 / 로그인 (workbot-ai와 통일 or 별도)
- [ ] 라이선스 키 발급 및 검증
- [ ] 기기 등록 (1계정 = N대 PC)
- [ ] 세션 관리 (로그아웃, 기기 해제)

### B-2. 결제 시스템
- [ ] 요금제 설계 (무료체험 / Basic / Pro / Enterprise)
- [ ] 결제 연동 (PayPal or 토스페이먼츠 or 카카오페이)
- [ ] 라이선스 만료 처리
- [ ] 자동 결제 (구독 갱신)
- [ ] 환불 정책

### B-3. API 엔드포인트
- [ ] POST /api/agent/auth — 라이선스 인증
- [ ] GET /api/agent/tasks — 작업 큐 조회 (Polling)
- [ ] POST /api/agent/result — 작업 결과 제출
- [ ] GET /api/agent/status — 에이전트 상태 보고
- [ ] POST /api/agent/command — 긴급 명령 (WOL, 종료)
- [ ] WebSocket /api/agent/stream — 실시간 명령 스트리밍

### B-4. 텔레그램 연동
- [ ] TG 명령어: /pc-on (PC 켜기)
- [ ] TG 명령어: /pc-off (PC 끄기)
- [ ] TG 명령어: /pc-status (PC 상태 확인)
- [ ] TG 명령어: /run (작업 지시)
- [ ] TG → 리치 → 작업 → 결과 → TG 보고 파이프라인 완성

### B-5. 통계/모니터링
- [ ] 에이전트 접속 로그
- [ ] 작업 실행 이력
- [ ] 리소스 사용량 (CPU/메모리)
- [ ] 에러 트래킹
