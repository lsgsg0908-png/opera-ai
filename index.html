// Frequently Asked Questions
OPERA AI는 어떻게 동작하나요?▼
OPERA AI (리치)는 고객님의 PC에 직접 설치되어 마우스와 키보드를 실제로 움직이며 작업을 수행합니다. 텔레그램으로 명령을 내리면 리치가 PC에서 직접 실행하고 결과를 알려줍니다.
설치가 어렵나요?▼
1분이면 설치 완료됩니다. Windows나 Mac에서 설치 파일을 다운로드하여 실행하기만 하면 됩니다. 별도의 복잡한 설정이 필요하지 않습니다.
어떤 PC에서 사용할 수 있나요?▼
Windows 10/11 및 macOS 12+ (Intel 및 Apple Silicon)를 지원합니다. 최소 4GB RAM, 500MB 여유 공간이 필요합니다.
토큰은 어떻게 계산되나요?▼
모든 작업은 토큰을 소비합니다. 간단한 명령은 적은 토큰, 복잡한 분석 작업은 더 많은 토큰을 사용합니다. 일일 토큰은 매일 자동으로 지급되며, 추가 토큰을 구매할 수 있습니다.
무료 체험은 어떻게 하나요?▼
카드 등록 후 3일간 무료로 모든 Pro 기능을 체험할 수 있습니다. 3일 이내에 취소하면 요금이 청구되지 않습니다.
PC가 꺼져있을 때는 어떻게 하나요?▼
Pro 플랜 이상에서 WOL(Wake-on-LAN)을 지원합니다. 텔레그램으로 PC를 원격으로 켜고 작업을 지시할 수 있습니다. 작업 완료 후 자동으로 PC를 종료할 수도 있습니다.
보안은 안전한가요?▼
3중 방어 체계로 보호됩니다. Layer 1: 실행 명령어 블랙리스트 (rm -rf 등 차단), Layer 2: AI가 위험 요청 자동 판단 및 경고, Layer 3: 반복 위반 시 계정 정지. 모든 작업 로그가 저장되어 추적 가능합니다.
결제는 어떻게 하나요?▼
신용카드 (Visa, Mastercard), PayPal, 토스페이먼츠, 카카오페이를 지원합니다. 모든 결제는 3D Secure로 보호됩니다. 연간 결제 시 17% 할인 혜택이 있습니다.
