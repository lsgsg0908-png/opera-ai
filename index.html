// FAQ
자주 묻는 질문
OPERA AI는 어떻게 동작하나요?▼
OPERA AI(리치)는 고객님의 PC에 직접 설치되는 AI 비서입니다. 사람이 마우스와 키보드로 하는 모든 작업을 리치가 대신합니다. 텔레그램이나 PC 창으로 명령을 내리면 리치가 직접 실행하고 결과를 알려줍니다. 별도의 복잡한 서버나 클라우드 설정이 필요 없습니다.
설치가 어렵나요?▼
1분이면 설치 완료됩니다. 설치 파일을 다운로드하여 실행하기만 하면 됩니다. 추가 설정, 회원가입, 복잡한 환경 구성이 필요하지 않습니다.
어떤 PC에서 사용할 수 있나요?▼
Windows 10/11 및 macOS 12+(Intel 및 Apple Silicon)를 지원합니다. 최소 4GB RAM, 500MB 여유 공간, 인터넷 연결이 필요합니다.
리치가 실제로 마우스와 키보드를 움직이나요?▼
네, 리치는 실제로 마우스 커서를 움직이고 키보드로 입력합니다. 프로그램 실행, 파일 열기, 웹 브라우징, 문서 작성 등 사람이 하는 모든 조작을 그대로 수행합니다. 작업하는 모습을 직접 지켜볼 수 있습니다.
토큰은 어떻게 계산되나요?▼
모든 작업은 토큰을 소비합니다. 간단한 명령(문서 검색, 번역)은 10~50토큰, 중간 작업(데이터 분석, 보고서 요약)은 100~300토큰, 복잡한 작업(대용량 데이터 처리, 코드 생성)은 500~2000토큰이 소비됩니다. 일일 토큰은 매일 자동으로 지급되며, 추가 토큰을 구매할 수 있습니다.
무료 체험은 어떻게 하나요?▼
이메일과 비밀번호만으로 3일간 Pro 기능을 무료로 체험할 수 있습니다. 3일 이내에 취소하면 요금이 청구되지 않습니다. 별도의 결제 정보 입력이 필요하지 않습니다.
보안은 안전한가요?▼
3중 방어 체계로 보호됩니다. Layer 1: 시스템 명령어/경로 블랙리스트로 위험한 명령 차단, Layer 2: AI가 위험 요청 자동 판단, Layer 3: 반복 위반 시 계정 정지. 모든 작업 로그가 저장되어 추적 가능합니다.
결제는 어떻게 하나요?▼
PayPal을 지원합니다. 신용카드(Visa, Mastercard, American Express) 및 PayPal 잔액으로 결제 가능합니다. 연간 결제 시 17% 할인 혜택이 있으며, 추가 PC 등록 시 50% 추가 토큰이 지급됩니다.
